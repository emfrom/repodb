# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's **Security → Report a vulnerability** private reporting workflow for this repository. Do not open a public issue for an unpatched vulnerability.

The repository maintainer is `@emfrom`; use the private report form to contact the maintainer. Include the affected version or commit, impact, and a minimal reproduction when safe. Do not include live credentials, private source data, or other secrets in the report.

There is no guaranteed response-time SLA. The maintainer will coordinate acknowledgement, investigation, remediation, and disclosure through the private advisory. Please do not publish details until coordinated disclosure has been agreed.

If a credential or token has been exposed, revoke or rotate it immediately and report the exposure privately. Security fixes and backports are assessed per release; the project does not currently promise a fixed support or backport window.
