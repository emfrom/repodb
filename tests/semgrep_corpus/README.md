# Semgrep language corpus (provisional)

This corpus is a provisional 25-language candidate set for issue #27; the final language/ranking decision and shared program semantics are pending in issue #28. It currently contains 50 checked-in source files (two per language), each 200–229 lines. The fixtures sketch the same small in-memory entity registry, audit-event type, and create/find/archive API. The primary entity name has a `V1` suffix so the history integration test can rename it to `V2` in a second commit.

The language list is intentionally a candidate, not a claim that these are objectively the top 25 by a particular popularity ranking. It is drawn from the Semgrep v1.181.0 OSS parser set. Move is represented as one high-level language using both Sui and Aptos parser alternatives; Rust uses Semgrep's `rust` parser.

`generate_fixtures.py` deterministically regenerates `sources/<language>/registry_{alpha,beta}.<extension>`. Each fixture test invokes the real Semgrep core v1.181.0 and verifies its AST and every `OriginTok` byte position against the source. The history test refreshes V1 and V2 with the same real core, then checks both versions' reachable commit/path/line references. A deterministic fake embedder is used for CLI indexing; no fake Semgrep core is used. The Semgrep runtime is required for source indexing and all CLI tests; ordinary `cargo test` fails if the pinned core is unavailable. `scripts/test-semgrep-core.sh` runs the real-core corpus and adapter gate. Install/provision Semgrep v1.181.0 first, then set `REPODB_SEMGREP_CORE` or `[tools].semgrep_core` in the XDG RepoDB config to its executable path. The tests make no network requests.
